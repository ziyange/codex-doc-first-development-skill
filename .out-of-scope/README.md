# Out of Scope

Each file in this directory records one rejected concept and why it was rejected, so the same idea does not need to be re-litigated. Read these before filing an issue or proposing a change.

Convention: one concept per file, named `<concept>.md`, each containing:

- **Concept**: what was proposed
- **Rejected on**: date
- **Reason**: why it does not fit the bar in [SCOPE.md](../SCOPE.md)
- **Alternative**: what to do instead (fork, personal `AGENTS.md`, or nothing)
